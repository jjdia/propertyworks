# PropertyWorks

**Manage. Buy. Sell. Renovate. Grow.**

PropertyWorks is an installable real-estate command center for rental management, acquisitions, sales, renovation projects, documents and portfolio reporting.

The current version is a static Progressive Web App. Data is stored locally in the browser. A production version should add secure authentication, a cloud database, document storage, tenant portals, payments and audit history.

Deployment refreshed after GitHub Pages enablement.
