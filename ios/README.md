# PropertyWorks iOS

This folder contains the native SwiftUI wrapper for PropertyWorks.

## Build
1. Open Xcode and create a new iOS App project named **PropertyWorks**.
2. Use SwiftUI.
3. Replace the generated app/content files with the Swift files in this folder.
4. Add `PropertyWorksWebView.swift`.
5. Select your Apple Developer Team in Signing & Capabilities.
6. Run it on your iPhone.

The native wrapper loads the hosted PropertyWorks web app at:
https://jjdia.github.io/propertyworks/

For App Store distribution, add proper authentication, cloud data storage, privacy disclosures, icons/screenshots, and App Store Connect metadata before submitting.
